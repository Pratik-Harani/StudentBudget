## Overview 
Student Budget is designed around the philosophy of envelope budgeting, a time-tested method of managing money. 

Each month, income is allocated into specific categories of expenses, like rent, groceries, travel, and savings. Then, the user spends money from that category. If all the income from a particular category has been spent, no more money can be used for that category until the next month. This is designed to give back financial control to the user and control unchecked spending. 


# Implementation
The app uses a Model-View-Controller (MVC) structure and object-oriented design. It is built using Python and customtkinter for the GUI. 


# Requirements
* Python 3.x
* customTkinter

Install customTkinter using 

```
pip install customtkinter
```

# How to Run
Make sure you have customTkinter and Python 3.x installed.

```
python3 main.py
```
